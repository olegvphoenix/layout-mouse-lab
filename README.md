# Редактор раскладки камер

Интерактивный HTML-макет для проверки жестов мыши. Откройте `index.html` в браузере. Все изображения встроены в файл.

Чтобы запустить на localhost, выполните в каталоге проекта `python -m http.server 8000 --bind 127.0.0.1` и откройте [макет](http://127.0.0.1:8000/#try).

- Выберите размер от 1×1 до 16×16 в группе «Создать сетку».
- Тяните центр камеры для переноса, границу или угол для изменения размера. Ctrl добавляет ячейку к выделению, Shift выделяет прямоугольник.
- Нажимайте буквы столбцов или номера строк, чтобы выбрать несколько полос. Потяните заголовок к стыку для перестановки группы.
- Плюс на стыке вставляет полосу. Минус рядом с заголовком подсвечивает удаляемую полосу при наведении и удаляет её при отпускании.
- «Отменить» возвращает предыдущую раскладку.

## Как работает редактор

Спецификация описывает пользовательские действия в опубликованном прототипе. Размер 3×5 означает три столбца и пять строк. Для проверки жеста смотрите на три момента: что подсвечено при наведении, что показывается при зажатой мыши и что остаётся после отпускания.

| За что взяться | Что сделать | Результат |
| --- | --- | --- |
| Центр камеры | Перетащить на соседнюю позицию | Перенос в пустое место или обмен с занятой камерой |
| Центр объединения или набора камер | Потянуть за любой выбранный кадр | Перенос с сохранением формы; вытесненные камеры занимают освободившиеся места |
| Сторона ячейки | Протянуть сторону на соседнюю позицию | Кадр тянется за ручкой. Пунктир удерживает выбранную линию в пределах ±2 CSS-пикселей от середины шага. Отпускание закрепляет показанный размер |
| Угол ячейки | Тянуть по диагонали | Сборка или разбор прямоугольника сразу по двум осям |
| Внешняя рамка или ручка крайней камеры | Потянуть наружу, задержать, вернуть мышь | Любая сторона добавляет несколько полос за один захват. При коротком ходе шаг уменьшается, удержание в дальней части хода продолжает рост. На углу каждую ось можно вернуть независимо |
| Плюс на стыке / минус у заголовка | Навести, нажать и отпустить; минус можно протянуть вдоль оси | Вставка пустой полосы / удаление выбранной полосы или диапазона |
| Буква или номер | Щёлкнуть нужные заголовки, потянуть один к стыку | Перестановка полос; после успешного сброса выделение снято |

### С каких раскладок начинать проверку

Добавьте параметры к адресу макета. Якорь `#try` открывает вариант для самостоятельной пробы.

| Адрес относительно сайта | Что проверить мышью |
| --- | --- |
| `/?sample=2x2#try` | «Вход 01»: увеличить угол до 3×3, увидеть пять затронутых соседей. Отдельно — перенести 2×2 вправо с обменом камер. |
| `/?sample=3x3#try` | Вернуть только правый столбец. Затем через отмену вернуться к 3×3 и освободить угол до 2×2. |
| `/?sample=alley-grow#try` | Верх «Аллеи 04»: 3×5 → 3×8 → 3×7 → 3×5. Угол «Моста 21»: 3×5 → 5×7 → 5×5. |
| `/?sample=trim-left#try`, `/?sample=trim-edges#try` | Вернуть пустой внешний край; на углу убрать лишь одну из двух полос обратным движением. |
| `/?sample=trim-16#try` | Проверить дрожание руки около порога на плотной сетке. Это отдельный пример с пустыми краями. |
| `/?sample=shrink-edge#try` | Сжать расширенную крайнюю камеру и увидеть автоматическое сокращение пустых полей. |
| `/?sample=inner-strips#try` | Удалить добавленные пустые полосы и занятую полосу; проверить обратимость через историю. |
| `/#try` | Проверить перенос несмежных B и D и повторный захват одной колонки, затем тот же сценарий для строк. |

### Как читать решения сессии

В итоговом интерфейсе прямоугольный выбор доступен через Shift, а геометрическое объединение выполняется ручками. В ранних итерациях исследовались отдельный режим «Область», обведение или два щелчка с подтверждением «Объединить», кнопка «Вернуть соседей», подписи и стрелки поверх видео, плюсы на внешнем кольце, команда удаления пустых краёв, боковая схема и меню «Строки и столбцы». Их заменили прямые жесты и предпросмотр на сетке. Уменьшенная наклонная копия при переносе заменена полноразмерными кадрами. Материалы сравнения с толстым UI, Nx Witness и FancyZones использовались при выборе жестов.

Паритет с толстым UI остаётся целью для интеграции в WebClient. Проверяемая здесь область — геометрия раскладки и размещение камер. Прототип работает с демонстрационными кадрами и локальной историей вкладки. Сохранение на сервер, параметры реальных видеопотоков, карты и панели, перенос из дерева устройств, FrameMerge, связи камер с информационной или тревожной панелью и очистка содержимого существующей ячейки требуют отдельной проверки при интеграции. Геометрическое объединение в данной спецификации сохраняет состав скрытых ячеек.

### Работа с OpenSpec

В репозитории настроен OpenSpec со схемой `spec-driven`, русским языком артефактов и интеграцией Codex. Актуальное поведение хранится в `openspec/specs/`. Новое предложение оформляется в `openspec/changes/`. Проверка из корня репозитория с установленным OpenSpec CLI:

```sh
openspec validate --all --strict --no-interactive
```
