# Редактор раскладки камер

Интерактивный HTML-макет для проверки жестов мыши. Откройте `index.html` в браузере. Все изображения встроены в файл.

Чтобы запустить на localhost, выполните в каталоге проекта `python -m http.server 8000 --bind 127.0.0.1` и откройте [макет](http://127.0.0.1:8000/#try).

- Выберите размер от 1×1 до 16×16 в группе «Создать сетку».
- Тяните центр камеры для переноса, границу или угол для изменения размера. Ctrl добавляет ячейку к выделению, Shift выделяет прямоугольник.
- Нажимайте буквы столбцов или номера строк, чтобы выбрать несколько полос. Потяните заголовок к стыку для перестановки группы.
- Плюс на стыке вставляет полосу. Минус рядом с заголовком подсвечивает удаляемую полосу при наведении и удаляет её по нажатию.
- «Отменить» возвращает предыдущую раскладку.
